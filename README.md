# Website Karang Taruna

Website organisasi Karang Taruna yang dibangun menggunakan Django dan NeonPostgreSQL.

## Fitur

- Beranda
- Berita
- Agenda
- Galeri
- Pengurus

## Teknologi

- Python
- Django
- NeonPostgreSQL
- Bootstrap

## Stack Production:
- Django 5.2
- Railway
- Neon PostgreSQL
- Cloudinary
- WhiteNoise
- Groq Chatbot
- Gemini Fallback
